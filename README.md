# 词阶 · 30天英语起步

面向零基础成人专升本考生的浏览器词汇学习工具。纯静态网页，无需登录，支持手机和电脑。

- 420个自编基础词与短语、入门例句、5篇阅读练习。
- 30/60分钟学习安排、间隔复习、易错词与进度备份。
- 学习数据保存在当前浏览器 localStorage，**不会自动跨设备同步**。换设备前在学习设置导出 JSON 备份，再导入新设备。
- 词库不是官方完整考纲，练习不是历年真题。

## 发布

GitHub Pages 使用 main 分支根目录发布。更新 index.html、style.css、app.js 或 words.js 并推送，即可更新网站。

## 本地使用

用静态 HTTP 服务提供本目录；不需要安装构建依赖。朗读使用设备的 Web Speech API，需设备支持英语语音。
